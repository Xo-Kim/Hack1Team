## 1. 개요

오프라인 매장에서 소비자가 거울 앞에 서는 순간은 구매 여정에서 감정이 가장 고조되는 접점이다. 그러나 그 다음에 벌어지는 일 — 직원이 다가와 응대하는 순간 — 은 전적으로 직원 개인의 감각과 경험에 의존한다.

Mood Mirror는 이 두 순간을 잇는다.

1. 카메라가 소비자의 착장·분위기를 읽고, LLM이 이를 분석해 **조명 연출과 음악으로 공간을 세팅**한다.
2. 동시에 **MCM 제품 라인업에서 카테고리별 추천 3종**을 선정하되, **이 결과는 고객 화면에 표시하지 않는다.** 오직 **직원 단말의 응대 카드**로만 전달된다.
3. 직원은 고객이 어떤 무드이고 무엇을 권해야 할지 이미 아는 상태로 다가간다. **"왜 이 제품이 당신에게 어울리는지", "왜 이것이 MCM인지"를 말하는 것은 사람이다.**
4. 마음에 드는 순간은 고객이 **자기 휴대전화로 직접 촬영**한다. 서비스는 사진을 찍지도, 만들지도, 보관하지도 않는다.

**조명과 음악은 목적이 아니라 전달 수단이다.** AI가 읽어낸 해석을 고객이 화면의 글자가 아니라 공간의 감각으로 먼저 만나게 하는 장치다. 분석 결과를 텍스트로 보여주는 순간 이 서비스는 진단 도구가 되고, 럭셔리 경험이 아니게 된다.

### 1.1 왜 추천을 고객에게 보여주지 않는가

럭셔리에서 추천은 정보 전달이 아니라 **관계의 산물**이다. 사람 입에서 나와야 가치가 매겨진다. 화면이 먼저 제품을 제시하면 직원은 그것을 읽어주는 사람이 되고, 경험은 이커머스 위젯으로 격하된다.

이 판단은 취향의 문제가 아니라 시장 구조의 문제이기도 하다. McKinsey는 럭셔리에서 **"의미는 만들어지는 것(meaning is made)"** 이며, AI 중개로 상품화 압력이 커질수록 **사람이 만든 의미와 브랜드 해석의 가치가 오히려 더 중요해진다**고 본다 (§2.4). 화면이 추천을 대신 말해버리면, 값이 오르고 있는 바로 그 자산을 스스로 버리는 셈이다.

따라서 역할을 분리한다.

|      | 고객 화면         | 직원 화면              |
| ---- | ------------- | ------------------ |
| 성격   | **감각**        | **지능**             |
| 내용   | 조명 · 음악 · 컨셉명 | 분석 결과 · 추천 3종 · 근거 |
| 판매   | 하지 않음         | 응대의 재료             |
| 맡는 일 | 욕망을 만든다       | 의미를 설명한다           |

> **경계**: "추천 이유"와 "브랜드 스토리"는 이 서비스의 산출물이 맞지만, **전달 경로는 화면이 아니라 사람이다.** 고객 화면에 제품명·순위·분석 원문이 나타나면 그것은 구현 실수이며, 서버가 그 경로를 갖지 않도록 API 자체를 고객용·직원용으로 분리해 두었다 ([API_SPEC](docs/API_SPEC.md)).

### 1.2 범위

해커톤 특성상 물리적 조명·음향 기기 제어는 범위에서 제외하고, **웹 화면에서 조명 효과를 시각적으로 연출하고 음악을 재생**한다. 단, 조명 출력은 하드웨어 중립 스펙으로 설계하여 실제 조명 연동이 어댑터 추가만으로 가능하도록 한다 ([EXPERIENCE_SPEC §1.3](docs/EXPERIENCE_SPEC.md)).

## 2. 문제 정의

### 2.1 고객 측

- 오프라인 피팅 경험은 온라인이 대체할 수 없는 핵심 접점이지만, 대부분의 매장 거울은 수동적인 도구에 머물러 있다.
- 럭셔리 매장에서 고객은 **직원이 다가오는 것에 부담을 느끼거나**, 반대로 **필요할 때 직원을 찾지 못해 이탈**한다. 이 둘 사이의 조절 장치가 없다.
- 매장 방문 경험이 기억에만 남고 **공유 가능한 형태로 남지 않는다.**

### 2.2 매장/직원 측

- 직원은 고객에 대한 정보 없이 접근한다. 첫 대화가 정보 수집에 소모되고, 응대 품질이 개인 역량에 좌우된다.
- 신입 직원과 베테랑의 응대 격차가 그대로 매출 격차가 된다.
- 고객이 무엇에 반응했는지는 대화로만 파악 가능해 데이터로 남지 않는다.

### 2.3 브랜드 측

- MCM은 현재 프리미엄·럭셔리로서의 인지 가치가 충분히 확보되어 있다고 보기 어렵다. 아웃렛·할인 노출로 인지 가격대가 흔들린 상태다.
- 이 상태에서 **가격 인상과 희소성 강화로 되돌리는 톱다운 전략은 성공 확률이 낮다.** 그 방식은 이미 그 자리를 지키고 있는 브랜드만 쓸 수 있다.
- Gen Z 접점에서의 **자발적 노출과 입소문**이 필요하나, 이를 유발하는 장치가 매장에 없다.

> 검증 필요: §2.3의 브랜드 인지 진단은 팀의 판단이며, 발표 전 **정량 근거(브랜드 인지도 조사·리셀 가격 추이·검색량 등) 1~2건 확보**를 권장한다 (§14 오픈 이슈).

### 2.4 시장 구조 변화 — 에이전틱 커머스

앞의 세 문제는 매장 안의 이야기다. 그런데 매장 밖에서 더 큰 변화가 이미 진행 중이고, 이 서비스의 존재 이유는 결국 거기에 걸려 있다.

**고객이 브랜드를 만나는 첫 지점이 상류로 이동하고 있다.** AI가 상품을 해석·비교·큐레이션하기 시작하면서, 의사결정은 *어디서 사는가*에서 *어디서 의도가 처음 표현되고 욕망이 점화되는가*로 옮겨가고 있다.

McKinsey의 2026년 5월 조사(럭셔리 머천트 90곳 · 소비자 300명)가 보여주는 현재 상태:

| 지표                            | 값                       | 의미                       |
| ----------------------------- | ----------------------- | ------------------------ |
| 럭셔리 소비자의 AI 어시스턴트 사용          | **85%** (자주 사용 **52%**) | 미래형이 아니다. **이미 일어난 일이다** |
| 2030년 AI 중개 럭셔리 구매 비중         | **39%** (소비자 추정)        | 소비자가 스스로 예상하는 값          |
| 같은 항목, 머천트 예상                 | **47%**                 | **파는 쪽이 더 높게 본다**        |
| 전 소비재 커머스 중 AI 에이전트 중개 (2030) | **$3~5조** (goods only)  | 럭셔리 한정 수치가 아님에 유의        |

McKinsey가 던지는 질문은 "AI가 럭셔리 여정을 중개할 것인가"가 아니다. 그건 이미 정해졌다고 본다. 실제 질문은 이것이다.

> **브랜드가 그 레이어를 클라이언트텔링을 심화·확장하는 데 쓸 것인가, 아니면 그 레이어를 남이 정의하도록 둘 것인가.**

#### 왜 이것이 MCM에게 특히 위험한가

AI가 상품을 **가격·사양처럼 비교 가능한 축**으로 평가하면, 그 축에서 이기는 브랜드만 살아남는다. 럭셔리 브랜드의 고유한 의미와 차별성은 그 비교표에 들어가지 않는다.

**MCM은 이 상품화 압력에 가장 취약한 위치에 있다.** §2.3에서 진단했듯 인지 가격대가 이미 흔들린 상태이므로, 스펙과 가격만 남은 비교표에서는 방어할 자산이 얇다.

#### 이 서비스의 대답

McKinsey는 같은 조사에서, 다음 세대 럭셔리 고객 상당수가 **전담 어드바이저를 가져본 적이 없을 것**이며 AI가 그 관계의 **확장 가능한 대리(scalable digital proxy)** 가 될 수 있다고 본다. 동시에 서비스·재량·속도 조절·안심이라는 **하이터치 레이어는 거래를 감싸는 포장이 아니라 거래의 본질적 일부**라고 못 박는다.

이 두 문장 사이에 이 서비스의 자리가 있다.

|                  | AI가 하는 일   | 사람이 하는 일 |
| ---------------- | ---------- | -------- |
| 착장·분위기 해석        | ✅ 수 초 안에   |          |
| 44종 카탈로그에서 후보 선별 | ✅ 순위와 근거까지 |          |
| 왜 어울리는지 설명       |            | ✅        |
| 왜 이것이 MCM인지 전달   |            | ✅        |
| 착용 안내·상담·마무리     |            | ✅        |

**즉 이 서비스는 AI 추천 서비스가 아니라 AI Clienteling 도구다.** AI를 고객 앞에 세우는 것이 아니라, 직원 뒤에 두어 직원이 원래 할 수 있었어야 할 응대를 하게 만든다. 해석 레이어를 외부 에이전트에 넘기지 않고 **MCM이 매장 안에서 직접 소유하는 것**이 전략적 목적이다.

> **발표 논지**: "AI 시대에 럭셔리가 위험한 이유는 AI가 사람을 대체해서가 아니라, **브랜드의 의미를 비교표의 한 칸으로 눌러버리기 때문**입니다. 저희는 AI를 고객 앞이 아니라 직원 뒤에 뒀습니다."

#### 확장 경로

지금은 매장 안에서 직원을 지원하는 도구지만, 제품 정보·재고·브랜드 콘텐츠를 **기계가 정확히 읽을 수 있는 형태로 구조화**해 두면 외부 AI 에이전트와의 연계까지 이어진다. 실제로 이번 구현의 카탈로그([ARCHITECTURE](docs/ARCHITECTURE.md))와 할루시네이션 차단 구조([ARCHITECTURE §3.2](docs/ARCHITECTURE.md))가 그 첫 단계다 — AI가 제품명을 지어내지 못하고 **등록된 ID만 고를 수 있게** 만든 것은, 지금은 오답 방지 장치지만 장기적으로는 브랜드가 자기 정보의 표현을 통제하는 수단이 된다.

> **인용 주의**: $3~5조는 McKinsey의 별도 에이전틱 커머스 연구에서 나온 **전 소비재(goods only) 수치**이며, 럭셔리 기사가 이를 인용한 것이다. 발표에서 "럭셔리 시장 규모"로 말하면 사실과 다르다. 럭셔리 논거로는 85% · 39% · 47%를 쓸 것.

## 3. 브랜드 전략 — 바텀업

### 3.1 전략 명제

일반적인 럭셔리는 **상위 계층 → 하위 계층**으로 욕망이 전이되는 톱다운 구조다. MCM에게는 반대 경로가 맞다.

**Gen Z가 먼저 소비하고, 그 소비가 SNS를 통해 가시화되면서 브랜드 가치가 위로 올라가는 바텀업 구조.**

### 3.2 왜 MCM에게 이것이 "전략적 선택"이 아니라 "복귀"인가

이 논거가 핵심이다. **바텀업을 새로 제안하면 도전이지만, 원래 그랬다고 말하면 진단이 된다.**

- MCM은 1976년 뮌헨에서 시작했으나, 브랜드에 문화적 자본을 부여한 것은 유럽 헤리티지가 아니라 **80~90년대 힙합·스트릿 씬이 이 브랜드를 자기 것으로 소비한 사건**이다.
- 브랜드 스스로도 **"New School Luxury"** 를 표방하며 이 계보를 자산으로 선언하고 있다.
- 즉 MCM의 진짜 자산은 *"오래된 유럽 명품"* 이 아니라 ***"서브컬처가 선택했다는 이력"*** 이다.

> **발표 논지**: "MCM에게 바텀업을 제안하는 것이 아니다. MCM은 원래 바텀업으로 만들어진 브랜드이고, 톱다운을 흉내 내는 동안 자기 자산에서 멀어졌다. 이 서비스는 원래 자리로 돌아가는 장치다."

### 3.3 레퍼런스 — Coach

바텀업 회복의 가장 정확한 선례, **Coach**다.

|         | **Coach**                                    |
| ------- | -------------------------------------------- |
| 출발      | 액세서블 럭셔리                                     |
| 문제      | **아웃렛 의존으로 브랜드 희석**                          |
| 회복 경로   | **Gen Z의 자발적 SNS 소비(TikTok·Tabby 백)로 인지 반전** |
| MCM 적합도 | **높음 — 문제 구조가 거의 동일**                        |

Coach는 **MCM과 같은 자리에서 출발해 바텀업으로 되돌아온 실증**이다.

### 3.4 전략적 긴장과 해소

바텀업 전략은 두 가지 모순을 안고 있다. 미리 해소해 두지 않으면 심사에서 그대로 반문이 된다.

**긴장 ①: 럭셔리(희소·절제) vs 바텀업(확산·노출)**

> **해소 — 접근은 희소하게, 가시성은 풍부하게.**
> 경험은 매장에서 그 순간에만 가능하고(희소), 고객이 찍어 나간 장면은 무한히 공유된다(확산). 희소성은 *접근*에 두고, 확산은 *고객의 자발적 기록*에 둔다. Supreme의 드롭 구조와 같은 원리다.

**긴장 ②: "직원 응대 = 럭셔리 가치" vs "Gen Z는 응대를 피한다"**

> **해소 — 응대의 성격을 판매(selling)가 아닌 호스팅(hosting)으로 정의한다.**
> 그리고 **"혼자 볼게요" 버튼이 이 전략의 필수 부품**이 된다. 거절할 수 있어야 수락이 진심이 되고, 진심으로 받은 응대만 공유된다. 이 버튼은 고객 배려 기능이 아니라 **바텀업 전략의 구성 요소**다.

### 3.5 확산 경로

```
매장 방문 (희소)
  → 조명·음악 연출 체험
  → 직원의 호스팅 (AI 보조, MCM 제품 착용)
  → 고객이 자기 폰으로 직접 촬영 ← 서비스는 관여하지 않는다
  → SNS 공유 (확산)
  → 매장 밖 Gen Z 도달 → 방문 유발
```

**이 경로에서 실제로 일하는 부품은 "공유"다.** 공유가 일어나지 않으면 전략은 실행되지 않고 매장 내 CX 개선으로 끝난다.

그런데 **서비스는 그 부품을 직접 만들지 않는다** ([EXPERIENCE_SPEC §3](docs/EXPERIENCE_SPEC.md)). 사진을 만들려면 저장·전송·삭제가 따라오고, 그것은 이 서비스가 내세우는 "아무것도 남기지 않는다"와 정면으로 부딪히기 때문이다. 대신 **찍고 싶어지는 장면을 만드는 데 집중한다.**

|          | 방식                       |
| -------- | ------------------------ |
| 결과물 생성   | 고객이 직접 촬영                |
| 통제 가능한 것 | **조명·구도·컨셉명 자막**         |
| 프라이버시 부담 | **없음**                   |
| 확산 측정    | **직접 측정 불가** (§5.2에서 대체) |

트레이드오프는 분명하다. **확산의 통제권과 측정 가능성을 프라이버시와 맞바꿨다.** 이 교환을 감수할 수 있는 이유는 §2.4에서 McKinsey가 짚은 대로 *신뢰가 장인정신만큼 중요해지는* 국면이고, "우리는 당신의 사진을 갖지 않습니다"가 그 자체로 브랜드 메시지가 되기 때문이다.

> **연출의 책임이 커졌다.** 서비스가 사진을 만들어주지 않으므로, 고객이 폰을 꺼내게 만드는 것은 전적으로 화면 연출의 몫이다. 조명·컨셉명 타이포그래피가 "찍을 만한 화면"인지가 §3.5 전체의 성패를 결정한다 ([EXPERIENCE_SPEC](docs/EXPERIENCE_SPEC.md)).

### 4.2 차별점 (포지셔닝)

기존 스마트 미러는 **편의(RFID·재고·사이즈)** 아니면 **커머스(AR 추천)** 에 집중했고, 클라이언트텔링 도구는 **과거 구매 데이터**에 의존했으며, 포토부스는 **브랜드·맥락과 무관**했다. Mood Mirror는 이 셋을 하나의 흐름으로 잇는다.

1. **AI 출력 비공개 원칙 (핵심)**: AI가 생성한 추천을 고객에게 보여주지 않는다. 전부 직원을 거쳐 사람의 말로 전달된다. *"AI가 추천해 줍니다"* 는 흔하지만 *"AI 출력은 고객에게 한 글자도 보여주지 않습니다"* 는 처음 듣는 문장이다.
2. **AI 세팅 + 사람 응대**: AI는 무대를 세팅하고 응대는 사람이 한다. 신입도 베테랑처럼 응대하는 도구가 되며, *AI가 판매원을 대체한다*는 흔한 서사의 반대편에 선다.
3. **수동 → 자동**: Ralph Lauren에서 사용자가 고르던 조명을, LLM이 착장·무드를 읽어 자동 큐레이션.
4. **연출이 사진에 실린다**: 조명 연출이 촬영 결과물의 미감 그 자체가 되므로, **공유되는 사진에 AI의 기여가 실제로 담긴다.** 포토부스는 프레임만 바뀌지만 우리는 빛이 바뀐다.
5. **하드웨어 프리**: RFID·전용 하드웨어 없이 카메라 + LLM만으로 구현 → 도입 비용이 낮아 전 매장 확산에 유리.
6. **고객 주도권**: "혼자 볼게요"를 동등한 비중으로 제공.

### 4.3 "먹히는가" — 수요 근거

- Ralph Lauren 스마트 피팅룸은 설치 후 **인게이지먼트 90%** 로 기대치를 상회.
- 인터랙티브 미러의 인게이지먼트는 70%+ 로, 수동형 디지털 사이니지(10~15%) 대비 압도적.
- AR/AI 미러 도입 매장에서 최대 40% 매출 상승, 반품 감소, UGC 생성 효과 보고 — 특히 Gen Z에서 반응.
- 국내 셀프 포토부스 시장의 확산은 **"찍고 공유하는 행동"이 이미 습관화되어 있음**을 보여준다. 새 행동을 학습시킬 필요가 없다.
- 결론: 거울 접점의 인터랙션과 촬영·공유 행동은 각각 검증된 수요이며, 경쟁 공백은 **둘을 잇고 그 사이에 사람의 응대를 넣는 구간**에 있다.

> **리스크 대응**: 발표에서 신선함의 위치를 명확히 할 것. 조명 변경 자체가 아니라 **①AI 출력을 고객에게 감춘다 ②그 정보가 직원 응대로 간다 ③연출이 공유 사진에 실린다** 는 세 가지 연결이다. Ralph Lauren 사례를 아는 심사위원에게, 그 사례가 멈춘 지점(화면 안에서 완결)에서 한 걸음 더 간다는 구조로 선제 설명한다.

### 5.1 North Star Metric

**완주 세션 수** — 연출을 경험하고, 응대 인계 또는 자율 관람까지 마친 세션의 수.

이 지표는 두 개의 사업 목표를 담는다.

- 하위 지표 A: **응대 인계 완료 수** (매장 CX / 매출 축)
- 하위 지표 B: **연출 완료 후 체류 시간** (바텀업 확산 축의 대리 지표 — 아래 참고)

> **확산 축은 직접 측정할 수 없다.** 서비스가 사진을 만들지 않으므로 "사진 전달 완료 수"를 셀 수 없다. 고객이 자기 폰으로 찍는 행위는 서버에 흔적을 남기지 않으며, **이를 감지하려는 시도 자체가 "아무것도 관측하지 않는다"는 약속을 깬다.** 따라서 직접 측정을 포기하고 대리 지표로 옮긴다.

> 
> 이 약화는 감수한 결과지, 놓친 것이 아니다. **확산을 정확히 세려면 고객 행동을 관측해야 하고, 그 순간 프라이버시 우위가 사라진다.** 파일럿에서는 체류 시간으로 "찍을 만한 화면이었는가"를 간접 판단하고, 실제 확산 여부는 매장 단위가 아닌 브랜드 단위 추세로만 본다.

### 5.3 데모 성공 기준 (해커톤)

- 터치 시작부터 조명·음악 연출까지 **8초 이내**
- 서로 다른 착장 3가지 이상에서 뚜렷하게 다른 조명·음악·추천 결과 시연
- **고객 화면 + 직원 화면 동시 시연** — 고객이 버튼을 누르는 순간 직원 태블릿에 응대 카드가 뜨는 것을 심사위원이 목격
- **심사위원이 자기 폰으로 연출 화면을 찍고 싶어지는지**를 현장에서 확인 (권유하지 않고 관찰)
- 추천 제품이 실제 MCM 라인업의 실존 제품임을 보증 (할루시네이션 0회)
- **서버 어디에도 이미지가 남지 않음을 시연 중 증명** — 저장 경로 부재를 코드·로그로 제시
- 치명적 실패(무한 로딩, 재생 불가) 0회 — 폴백으로 커버

### 브랜드 톤 정합성 (10점)

- Visetos 패턴·코냑 컬러 등 브랜드 시각 자산을 미러 UI 프레임과 **포토 프레임**에 적용.
- 연출 컨셉명(예: "Munich Midnight", "Seoul Street")을 브랜드 헤리티지(뮌헨 기원, 서울 기반)와 연결.
- **AI가 전면에 나서지 않는다** — 기술 과시가 아니라, 아예 고객 화면에서 보이지 않는다 (§1.1). 이 절제 자체가 브랜드 톤이다.
- **럭셔리 응대의 핵심인 "사람"을 지우지 않는다.**

## 8. 사용자 시나리오

### 8.1 고객 플로우

1. 고객이 MCM 매장에서 아이템을 착용하고 미러(대형 디스플레이) 앞에 선다.
2. 화면의 시작 버튼을 터치한다. (촬영·분석 동의 문구 포함)
3. 카메라가 **분석용 스틸컷**을 촬영하고 서버로 전송한다. *(이 이미지는 저장되지 않는다 — §16)*
4. 분석 대기 중 **단계별 진행 상황**을 노출한다. ("분위기를 읽는 중 → 컬러 팔레트 추출 → 조명 세팅")
5. 분석 완료와 함께 **화면 조명이 착장 무드에 맞는 색·밝기로 서서히 전환**되고, **매칭된 음악이 재생**되며, 연출 컨셉명이 브랜드 타이포로 표시된다.
   - *동시에 백그라운드에서 제품 추천이 생성되어 직원 화면으로 전송된다. 고객 화면에는 어떤 흔적도 남지 않는다.*
6. 고객은 연출된 거울 앞에서 착장을 확인한다.
7. **분기 선택 화면** — 두 가지 선택지가 **동등한 비중**으로 제시된다.
   - **"직원 도움 받기"** → 8-a
   - **"혼자 볼게요"** → 8-b
8. 분기별 진행:
   - **8-a** 직원에게 즉시 알림 + 응대 카드 발송 (§8.2). 화면에는 "곧 도와드리겠습니다" + 예상 대기 표시. 직원 도착 시 **응대 모드**로 전환 — 조명 유지, **음악 볼륨 자동 감소(ducking)**. 이후 대면 응대는 전적으로 직원이 수행한다.
   - **8-b** 연출만 유지. 직원 화면에는 **"응대 불필요"** 상태로 표시되어 접근하지 않는다.
9. **연출 유지 구간** — 8-a는 응대 중·응대 종료 후, 8-b는 자율 관람 내내 조명·음악·컨셉명이 그대로 유지된다.
   - **서비스는 촬영을 권유하지 않는다.** 버튼도, 카운트다운도, 안내 문구도 없다.
   - 고객이 원하면 자기 휴대전화로 화면과 자신을 직접 찍는다. 서버는 이를 알지 못한다.
10. 타임아웃(무입력 3분) 또는 리셋 터치로 대기 화면 복귀. 세션의 분석 결과는 메모리에서 폐기된다 ([PRIVACY](docs/PRIVACY.md)).

> **왜 촬영 버튼을 두지 않는가**: 버튼을 두는 순간 서비스가 결과물의 생산자가 되고, 저장·전송·삭제 책임이 따라온다. 그것을 지우면 [PRIVACY](docs/PRIVACY.md)의 "아무것도 남기지 않는다"가 조건부 약속으로 내려앉는다. 대신 **응대가 끝난 뒤에도 연출을 유지**해, 직원이 가져온 MCM 제품을 착용한 상태에서 고객이 스스로 찍을 시간을 만든다. 바텀업 확산 경로(§3.5)는 여기서 닫히되, 닫는 주체가 서비스가 아니라 고객이다.

### 8.2 직원 플로우

1. 직원 단말(태블릿/모바일)에서 직원용 화면(`/staff`)을 상시 대기 상태로 띄워둔다.
2. 고객이 도움을 요청하면 **알림 + 응대 카드**를 수신한다.
3. 응대 카드 내용:
   - 미러 위치 / 세션 시작 시각 / 경과 시간
   - 분석된 무드·스타일·컬러 팔레트 + 연출 컨셉명
   - **카테고리별 추천 3종** (이미지·제품명·순위·추천 이유·매장 내 위치)
   - "매장 재고 확인 필요" 상시 표기 (재고 미연동)
   - **원본 사진은 전달되지 않는다** — 분석 결과 텍스트만 ([PRIVACY](docs/PRIVACY.md))
4. 직원은 카드를 확인하고 **"응대 시작"** 을 탭한 뒤 고객에게 이동한다. (다른 단말에서 즉시 잠금 표시 — 중복 응대 방지)
5. 응대 종료 후 **간단 설문**을 입력한다 (P1, F-17):
   - 추천 아이템 중 실제로 제시한 것
   - 고객 반응 (관심 / 보통 / 무관심)
   - 결과 (구매 / 미구매 / 이탈)

## 13. 향후 확장 (발표용 컨셉 제시, 미구현)

### 13.1 응대 데이터 기반 추천 개선 루프

고객에게서 데이터를 수집하지 않는다. **직원이 응대 중 관찰한 내용을 설문 형식으로 입력**하는 방식으로만 데이터를 얻는다 (F-17). 이 설계는 [PRIVACY §4](docs/PRIVACY.md)의 "개인 식별 미수집" 원칙과 충돌하지 않는다.

**수집 단위: 개인이 아니라 익명 세션**

```json
{
  "session_id": "anon-8f2c...",
  "mood_vector": { "palette": [...], "formality": 0.6,
                   "style_tags": [...], "energy": 0.6 },
  "recommended_ids": ["MCM-BAG-014", "..."],
  "staff_presented_ids": ["MCM-BAG-014"],
  "customer_reaction": "interested | neutral | uninterested",
  "outcome": "purchase | no_purchase | left"
}
```

개인 식별자가 없으므로 축적되는 지식은 *"이 사람이 무엇을 좋아했다"* 가 아니라 ***"street-luxury 무드에서 코냑 벨트 추천의 채택률은 72%"*** 라는 **집단 통계**다. 개인화는 포기하지만, 목표였던 **일반화**는 그대로 달성된다.

**활용처 — 모델 학습이 아니다**

이 규모에서 LLM 파인튜닝은 불가능하고 불필요하다. 데이터가 실제로 쓰이는 곳은 두 군데다.

1. **프리필터 가중치(w1·w2·w3) 보정** — 수백 건이면 유의미한 조정이 가능하다.
2. **GPT 랭킹 호출의 few-shot 예시 축적** — "이런 무드에는 이런 추천이 채택되었다"는 실제 사례 주입.

**현실 감각**: 파일럿 1개 매장 × 하루 30세션 × 30일 ≈ 900건. 무드 클러스터가 5~8개면 클러스터당 100여 건. **가중치 보정에는 충분하고 모델 학습에는 턱없이 부족하다.** 발표에서도 "학습한다"가 아니라 **"축적된 응대 데이터로 추천 규칙을 보정한다"**로 표현한다 — 정확하고, 검증 가능해서 오히려 강하다.

**신호 품질**: 고객의 👍/👎보다 **직원이 관찰한 행동 신호**(실제 제시 여부, 관심도, 구매 결과)가 훨씬 강하다. AI 추천을 고객에게 보여주지 않기로 한 결정(§1.1) 덕분에, 데이터의 유일한 입구가 직원 설문이 되고 그것이 더 나은 신호가 된다.

### 13.2 기타 확장

- **실제 조명·음향 연동**: Philips Hue / DMX512 어댑터, 지향성 스피커 기반 존 단위 제어 ([EXPERIENCE_SPEC §1.3](docs/EXPERIENCE_SPEC.md)).
- **온프렘 VLM 전환**: 폐쇄망 운영으로 이미지가 매장을 벗어나지 않는 구조 ([PRIVACY §2](docs/PRIVACY.md)).
- **재고 연동**: 응대 카드에 실시간 재고·사이즈 표시.
- **SNS 실게시**: 다운로드 페이지 → 인스타그램 공유 API.
- **다중 매장 대시보드**: 매장별 무드 분포·추천 채택률 비교.

## 14. 오픈 이슈

- [ ] 서비스 정식 네이밍 — 포지셔닝이 "AI 세팅 + 사람 응대 + 사진"으로 확장되어 `Mood Mirror`가 일부만 설명함. 후보: `Mirror & Host`, `Prelude`(응대의 전주곡), `Cue`(무대 큐 + 응대 신호), `MCM Moment`
- [ ] **§2.3 브랜드 진단의 정량 근거 확보** — 발표 전 인지도 조사·검색량·리셀 가격 추이 등 1~2건. 파트너사 앞 발언이므로 톤 조절도 함께 검토
- [ ] **발표 부스 조도 확인** — 조명 연출과 사진 품질이 동시에 달림. 저조도 위치 확보 가능 여부 사전 문의
- [ ] 직원 화면 시연 방식 — 태블릿 실물 거치 vs 화면 미러링 vs 2분할 송출
- [ ] **화면에 브랜드 표식을 어디까지 둘 것인가** — 고객이 화면을 찍었을 때 MCM이 드러나야 하지만, 광고처럼 보이면 공유되지 않는다
- [ ] Vision LLM 모델 선정 및 비용/지연 벤치마크 (1차 Vision + 2차 텍스트 2회 호출 기준)
- [ ] 제품 카탈로그 36종 선정 기준 — 카테고리별 가격대·라인·컬러 분포 배분
- [ ] MCM 무드 가이드 (조명 프리셋 5종 + 무드 태그 사전) 정의 — 브랜드 리서치 필요
- [ ] 촬영 동의 문구 법적 검토 수준 결정 (해커톤 수준 vs 실서비스 수준) 및 배경 제3자 촬영 대응
